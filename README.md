This Python script generates a secure, random password consisting of:

- Uppercase letters (A–Z) **excluding** `O`
- Lowercase letters (a–z) **excluding** `l`
- Digits `2–9` (excluding `0` and `1`)

## ✅ Features

- Password length: configurable (default: 25 characters)
- Excludes visually ambiguous characters (`l`, `O`, `0`, `1`)
- Easy to integrate into other scripts
